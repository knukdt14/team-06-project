## 1. 결정: "답이 실린 모든 페이지"를 정답으로 인정

**기준:** 질문의 핵심 숫자·조건이 온전히 실려 있어, retriever가 그 페이지를 가져오면
LLM이 정답을 만들 수 있는 페이지 전부. references.csv의 page에 `;`로 구분해 기록.

예: Q3(자녀세액공제) `page = 6;182` — 요약 p.6과 상세 챕터 p.182 중 하나만 찾아도 hit.

**선정 방법 (근거):**
1. PDF 원문에서 주제 키워드 + 핵심 숫자가 **공존하는 페이지** 검색 (예: "자녀세액공제"+"55만원")
2. 실제 LLM이 정답을 만들었을 때 인용한 근거 페이지와 교차 확인
3. 부록·서식·색인 페이지는 제외

## 2. 검증: 새 기준이 실제 답변 성패와 일치하는가

기존 검색 결과(retrieved_pages)를 새 기준으로 재채점:

| 실험 | 구 기준 Hit@3 | **새 기준 Hit@3** | 새 기준 실패 문항 | 실제 답변 실패 |
|---|---|---|---|---|
| baseline (1000/200) | 0.154 | **0.769** | Q1, Q9, Q10 | Q1, Q9, Q10 ✅ 일치 |
| cs500 (pre_header) | 0.385 | **0.923** | Q10 | (Q1·Q4는 생성 문제) |
| cs500+머리말 제거 | 0.462 | **0.923** | Q10 | Q10 ✅ 일치 |

→ **새 기준의 검색 실패 = 실제 답변 실패.** 검색 지표가 드디어 실제 성능을 반영한다.
→ MRR은 머리말 제거로 0.731→0.808 개선 (같은 hit라도 정답 페이지 순위가 올라감).
