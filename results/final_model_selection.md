## 1. 재현성 확인 — bge-m3+dedup+top_k=3+Upstage 4회 반복

동일 설정(temperature=0 수정 반영 후)을 4회 실행(cs500 3회 반복과 같은 목적):

| 실행 | numeric_acc | numeric_perfect | condition_recall | BERTScore | 응답시간 |
|---|---|---|---|---|---|
| 1 (10:13) | 0.8718 | 0.7692 | 0.8846 | 0.7031 | 2.30s |
| 2 (10:32) | 0.8462 | 0.7692 | 0.9231 | 0.7095 | 2.08s |
| 3 (10:40) | 0.8462 | 0.7692 | 0.8846 | 0.7190 | 2.06s |
| 4 (10:41) | 0.8462 | 0.7692 | 0.9231 | 0.7181 | 1.95s |
| **평균 (변동폭)** | **0.853 (±0.026)** | **0.769 (변화 없음)** | **0.904 (±0.038)** | **0.712 (±0.016)** | **2.10s** |

- **numeric_perfect(완벽 정답 문항 수)와 error_counts의 E6(숫자 오류 건수=3)이 4회 전부 완전히
  동일** — 노이즈가 아니라 **구조적으로 재현되는 결과**임을 확인.
- numeric_acc 변동폭(±0.026)은 재현성 실험(repro_cs500.md, Gemini 기준)에서 확보한
  노이즈 기준과 거의 일치 — Upstage도 같은 성격의 API 잔여 노이즈를 보인다.
- **결론: 이 조합의 "진짜" numeric_acc는 0.85 안팎으로 안정적으로 수렴한다.**

## 2. top_k=2 vs top_k=3 — 승부 없음, 안전 마진 우선으로 k=3 채택

| | k=2 | k=3 |
|---|---|---|
| Upstage numeric_acc | 0.872 | 0.846(4회 평균 0.853) |
| Upstage condition_recall | 0.923 | 0.904(4회 평균) |
| Upstage 응답시간 | 2.05s | 2.10s(4회 평균) |
| OpenAI numeric_acc | 0.782 | 0.795 |

검색 지표(이희영 topk_effect.md: Hit@k·MRR 완전 동일)에 이어 답변 지표도 두 모델 모두
k=2·k=3 차이가 노이즈 범위 안이고, 응답시간도 유의미한 차이가 없다. **효율(k=2) 이득이
없으므로 가이드라인 §9·이희영의 제안대로 안전 마진이 있는 k=3을 최종 채택.**

## 3. Upstage vs OpenAI(gpt-5.4-mini) — Upstage 확정 (동률 아니었음)

| | Upstage (k=2·k=3) | OpenAI (k=2·k=3) |
|---|---|---|
| numeric_acc | 0.846 ~ 0.872 | 0.782 ~ 0.795 |
| condition_recall | 0.885 ~ 0.923 | 0.808 ~ 0.898 |
| E6(숫자 오류) | 3건 (전 실행 고정) | 4~5건 |

이전 단일 실행 비교에서는 두 모델이 numeric_acc 0.872로 동률처럼 보였으나, k=2 데이터와
반복 실행을 추가하니 **Upstage가 두 k값·모든 반복에서 일관되게 우세**함이 드러났다
(격차 0.05~0.09, 노이즈 밖). 이전의 "동률"은 단발성 노이즈였다.

## 4. dedup의 트레이드오프 — 솔직한 평가

dedup 적용 전 Upstage: numeric_acc 0.9231(12/13 완벽), dedup 후 평균 0.853(10/13 완벽,
4회 전부 동일). **Q8(검색 완전 실패 → 완전 정답)을 고쳤지만, 다른 2문항 정도의 정밀도를
대가로 치렀다** — 4회 반복에서 이 패턴이 구조적으로 재현되어 노이즈로 치부할 수 없다.

그럼에도 dedup 채택을 유지한다: 실사용 관점에서 **"문서에서 찾을 수 없습니다"라는 완전한
검색 실패**가 **이미 대체로 맞는 답의 일부 세부사항 누락**보다 더 나쁜 실패 유형이기
때문이다(가이드라인 §22 오류 심각도 관점에서 E3> E6/E7). 이 판단은 수치가 아니라
가치 판단이므로 발표 시 근거로 명시할 것.

## 5. 최종 확정 파이프라인

| 구성 요소 | 값 |
|---|---|
| PDF 전처리 | 머리말 제거 (이수민) |
| chunk_size / overlap | 500 / 100 |
| 임베딩 | BAAI/bge-m3 (이희영 §8) |
| 검색 | similarity + 페이지 dedup (fetch_k=15) |
| top_k | 3 |
| LLM | Upstage solar-pro (temperature=0) |
| 프롬프트 | basic (다음 실험 대상) |

**"최고 품질"과 "가성비"가 이번에도 같은 조합으로 수렴한다** — Upstage가 품질 1위이면서
Gemini 대비 응답시간이 약 3배 빠르다(2.1s vs 6.5s). for_teamleader.md §23이 요구한
"두 가지 결과 제시" 요건이 사실상 하나로 합쳐지는 좋은 발표 포인트.
